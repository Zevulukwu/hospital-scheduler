# hospital-scheduler
A Java scheduling system to manage healthcare professionals' diaries with a console menu and swing GUI

## Features
- Add, edit and delete health professionals
- Add, edit and delete appointments
- Undo the last action
- Save and load diaries to file
- Search for common free slots across professionals' diaries
- Console menu and Swing GUI front-ends

## Technologies
Java, Swing, OOP, HashMap, ArrayList, Stack, java.time (LocalDate/LocalTime), java.io serialization

## How to run
. Compile all files: 'javac*.java'
. Run: 'java Main'
. Choose option 1 for GUI or option 2 for console menu
